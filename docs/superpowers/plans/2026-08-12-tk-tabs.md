# タスク / GitHub タブ分割 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** タスクと PR を1本のリストに混ぜている現状をやめ、`[` / `]` で切り替える2つのタブに分ける。

**Architecture:** `domain.SortInbox` を `SortTasks` / `SortPRs` に割り、`usecase.Inbox` は `Tasks()` / `PRs()` の2本を返す。TUI は `Model.tab` に応じてどちらかを `m.items` に入れる。`m.items` を読む既存コード（`selected` / `listView` / `aiExec`）は無改造で動く。追加と削除を別タスクに分け、各タスクの終わりで常にビルドとテストが通る状態を保つ。

**Tech Stack:** Go 1.26 / bubbletea v2 (`charm.land/bubbletea/v2`) / lipgloss v2 / 標準 `testing` のみ

**Spec:** `docs/superpowers/specs/2026-08-12-tk-tabs-design.md`

## Global Constraints

- 依存は **adapter → usecase → domain の一方向**。逆流させない。
- `internal/domain` が import してよいのは標準ライブラリのみ。
- bubbletea は **v2**。`View() tea.View`、`tea.KeyPressMsg`、スペースキーは `msg.String() == "space"`。v1 の記憶で書くとコンパイルが通らない。
- モジュールパスは `charm.land/...`。`github.com/charmbracelet/...` ではない。
- テストフレームワークは足さない。標準 `testing` のみ。
- 実装が分かるだけのコメントは書かない。「なぜ」が自明でない箇所にだけ書く。
- コミットメッセージは Conventional Commits 形式、subject は日本語、末尾に句点を付けない。`Co-Authored-By` 署名は付けない。
- **push / PR 作成はしない。** ローカルのコミットまで。
- lipgloss の `Width`/`Height` は枠線込みかつ最小値であって上限ではない。レイアウトのテストは「端末の幅・高さに収まる」形で書く。
- タブ行に色やスタイルは使わない。角括弧だけで選択状態を示す。

```go
// SortTasks / SortPRs の並び順は固定。ユーザーが変更する手段は用意しない。
// タスクは自分で書いた順序に意味があるので並べ替えない。
func SortTasks(tasks []Item) []Item {
	out := make([]Item, 0, len(tasks))
	for _, it := range tasks {
		if !it.Done {
			out = append(out, it)
		}
	}
	for _, it := range tasks {
		if it.Done {
			out = append(out, it)
		}
	}
	return out
}

// PR は「他人を待たせているもの」を先に出す。
func SortPRs(prs []Item) []Item {
	out := make([]Item, 0, len(prs))
	for _, it := range prs {
		if it.Role == RoleReview {
			out = append(out, it)
		}
	}
	for _, it := range prs {
		if it.Role != RoleReview {
			out = append(out, it)
		}
	}
	return out
}
```

```go
	right := m.width - left

	body := lipgloss.JoinHorizontal(

	}

	tabs := m.tabBar()
```
